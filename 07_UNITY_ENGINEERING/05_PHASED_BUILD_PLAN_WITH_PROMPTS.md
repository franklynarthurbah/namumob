# Phased build plan with paste-ready prompts
> Read after: README + master prompt · Run one phase per session/branch. Each prompt assumes the master prompt and `CLAUDE.md` are loaded. Never start a phase before the previous gate is ticked in `docs/STATE.md`.

## How to use a prompt
Paste the block, let Opus read the listed files, review its plan, then let it implement. At the end: run the gate checklist, commit, update `docs/STATE.md`.

---
